# Student Performance Analytics

A Python-based data analytics project that evaluates student academic performance using Pandas and NumPy.

## 📌 Project Overview

Student Performance Analytics is a beginner-friendly Python project designed to analyze student marks and attendance. It processes student data, calculates performance statistics, and generates results to help understand academic performance.

The project demonstrates the practical use of Python libraries for data analysis and CSV file processing.

## 🎯 Objectives

- Analyze student academic performance.
- Calculate total and average marks.
- Evaluate subject-wise performance.
- Assign grades based on marks.
- Determine pass/fail status using marks and attendance.
- Identify students with the highest and lowest performance.

## ✨ Features

- Student data processing using Pandas.
- Numerical calculations using NumPy.
- Total and average marks calculation.
- Grade calculation.
- Pass/fail evaluation.
- Subject-wise average analysis.
- Identification of maximum and minimum performance.
- Export of processed results to a CSV file.

## ▶️ How to Run

Execute the following command in your terminal:

bash
python3 main.py


The program will process the student dataset and display the calculated results.

## 📈 Pass/Fail Criteria

A student passes when both conditions are satisfied:

- Every subject mark is at least 40.
- Attendance is at least 75%.

If either condition is not satisfied, the student is classified as failing.

## 📁 Output

The program displays student performance results, including the statistics and grades implemented in the project.

It also saves the processed results to result.csv.
